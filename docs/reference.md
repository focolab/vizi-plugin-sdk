# API index

Every public name in `vizi_plugin_sdk`, with the first paragraph of its
docstring. The rest of the guide explains these by task; the docstrings
are the reference. Generated by `scripts/gen-api-index.py`.

## Classes

| Name | Summary |
|---|---|
| `AmbiguousSegment` | Two installed segments answer one `(purpose, subject)`. |
| `Appearance` | The host's theme and the colors it draws panels with (§8.4), as `(r, g, b, a)` tuples: what a plugin that renders its own pictures -- a plot pushed to an `image` -- needs to match them. `hex` gives one as `"#rrggbb"`, and `hex_colors` all of them. |
| `AppliedFilter` | The processing stage voxels passed through, when they are not the file's own -- Apply Filter's stage, as the host applied it. |
| `AssetUnavailableError` | The manifest did not declare an asset or it is not provisioned yet. |
| `Cancelled` | Raise from a handler that stopped because the host canceled its work; the request is answered `Error{CANCELLED}`, which is not a fault. |
| `ChannelName` | One channel's name, and where it came from. |
| `Chunk` | A chunk source's answer: bbox-tight `(Z, Y, X)` u8/u16 labels on the WANTED level's lattice, and where their origin sits in that level's voxel indices. Return a bare array for a volume at the origin, or `None` for an empty chunk (a state, not a removal). |
| `ChunkWant` | One (level, t) volume the host wants from a chunked overlay (`control_plane_protocol.md` §5.7). `t` is `None` for a `static` overlay, whose one volume per level serves every timepoint. |
| `Column` | A projection column. `kind` says which axis was collapsed: for `KIND_COLUMN_YX` the coordinates are `(y, x)` and the range is `z`, and so on (`KIND_COLUMN_ZX`, `KIND_COLUMN_ZY`). The range is half-open. |
| `CommandContext` | What a `@command` handler receives: the session's handles and the invocation's `args`. |
| `DeclarationError` | The declared interface cannot be built into a manifest. |
| `EdgeBox` | A box in edge coordinates, level-0 voxel units -- `Geometry.crop`. |
| `ExportDescriptor` | What an exporter's `begin` receives: the whole-artifact geometry the host declared in `OpenExport`, the output target, and what the artifact was derived from. |
| `FeatureUnavailable` | A plugin asked for a feature its session does not have. |
| `Follow` | One running Follow (§8.15), handed to a `follow` handler. |
| `HostClient` | Plugin-initiated host requests — `ctx.host`. |
| `HostDataArray` | A host-read array stamped with the dataset open generation, and with the `AppliedFilter` its voxels passed through, `None` when they are the file's own. An exporter's `write` volumes are these too, at `open_generation` 0: an export names no generation. |
| `HostError` | The host answered a data-access request with `host_error`, the reply was malformed, it timed out, or the session ended first (`SessionEnded`). `kind` is a `pb2.Error.Kind` value (0 for timeouts, malformed replies and a session that ended -- none of them is an answer from the host). |
| `HostViewState` | The host's active-view snapshot — `ctx.host.view_state()`. |
| `InclusionMask` | `HostClient.read_roi_inclusion`'s mask, with the host's own count of the voxels it covers -- checked against the mask, so a plugin can report the host's measurement footprint without recounting. |
| `InputEvent` | InputEvent(gen: 'int', t: 'int', interaction: 'int', seq: 'int', epoch: 'int', target_id: 'int', target_part: 'int', tool: 'int', channels: 'int', phase: 'int', view_id: 'int', level: 'int', mods: 'int', click_count: 'int', target_kind: 'int', payload_kind: 'int', position_flags: 'int', action: 'int', position: 'Position \| None', usable: 'bool' = True) |
| `NewChannel` | A channel the stage appends (§3 `adds`). `key` is plugin-local; the host assigns the index and the arm says which (`StageSlot.add_channel`). |
| `NoRegion` | No installed segment offers the arena a handle needs. |
| `Notification` | A decoded `D`. `mask` is the 512-bit region mask as one Python int, bit `r` naming region `r` — which is exactly the record's little-endian `[8..72)` read as a number, and therefore both of `D` §1's formulations at once. |
| `OverlayHandle` | Push typed overlay draw lists for one manifest-declared overlay id. |
| `PaneState` | What the host arranged for one pane, as this plugin acknowledged it (`control_plane_protocol.md` §8.10, §8.11): the dataset geometry the epoch stands for, the visible channels at index >= 15, and the time mapping. Read-only and already installed -- the gate guarantees an `E` record under this epoch arrives only after this state did, so a tool handler reads it with no round trip. |
| `PanelHandle` | Push state patches for one declared panel. Thread-safe (patches ride the outbound queue); last-write-wins per widget on the host side. |
| `PendingRequest` | One request to the host, in flight -- what the `*_async` forms of `HostClient` return, shaped like a `concurrent.futures.Future`. |
| `PluginContext` | The session's handles, as a `@reader` or `@exporter` class receives them: **construct the class with one parameter and it is this** -- `def __init__(self, ctx)` -- and a class with none is constructed bare. |
| `Ray` | Ray(camera: 'Voxel', far: 'Voxel', entry_frac: 'float', roll: 'float') |
| `RayAndPicked` | The ray, and the host's pick along it (`E` §3). `picked` is the front of the structure the host found under the cursor. `back_frac` says how far that structure runs BEHIND its front, as a fraction of the ray that is left there: the back point is `front + back_frac * (far - front)`, with `front` the picked voxel's center projected onto the ray. |
| `ReaderInfo` | What a reader's `open(uri)` returns: the dataset's shape + dtype, and whatever calibration the reader KNOWS. |
| `Refusal` | A reader or exporter refusing a request WITH A KIND -- the plugin-side twin of `HostError`, raised from `open` / `read_volume` / `begin` / `write` / `finish` and forwarded as `Error{kind, message}` (`reader_writer_contract.md` §1.5: the kinds are mandated because a third-party host may branch on them). `kind` is a `pb2.Error.Kind` value: `INVALID_ARGUMENT` for a file that is not this reader's format, `UNSUPPORTED` for one it recognizes and cannot serve, `OUT_OF_BOUNDS` for a chunk that contradicts the declared geometry. |
| `RefuseVolume` | Raise from `process` to refuse a volume (§6.3). **Before writing anything**: a refused volume is used as far as the previous stage got, so its data must still be that stage's output. |
| `RegionChange` | One region created, edited or deleted. `revision` is the one `get_rois` records carry (0 when deleted); `origin` is `"user"` or `"plugin:<id>"` -- a plugin's own regions are reported too. |
| `RegionsChange` | Subscription `"regions"`: which regions changed, never their geometry -- read those with `ctx.host.get_rois(region_ids=...)`. `reset` means everything held before is void (the session's first push, or a new dataset) and `changes` names every region there is. |
| `Rejected` | A shaper's answer that there is no shape for this position: during a drag the last one stays on screen; at the commit the edit reverts. |
| `SeriesChoice` | What `open(uri)` returns instead of a `ReaderInfo` when the file holds several images and none is honestly the one a user means. |
| `SeriesEntry` | One image of a file that holds several, as a reader lists it. |
| `SessionEnded` | The session ended before the host answered -- `Shutdown` arrived, the host's stream ended, or a fault ended it (`control_plane_protocol.md` §3.3). No reply can come any more, so every request still pending fails at once, before the shutdown hook runs, with `the session ended: <why>`; a request made afterwards fails the same way without being sent, with `the session has ended: <why>`. A handler waiting on the host across `Shutdown` hears this rather than its own timeout, and lets go of what it holds -- a lock the hook needs, say. |
| `SettingsDirUnavailableError` | The host did not provide a settings folder: the plugin is running outside vizi, or vizi could create neither the folder beside the manifest nor its fallback (the host's log says which). |
| `Shape` | A shaper's answer that says the handle did not land at `p1`. |
| `ShapeEdit` | A person editing a region whose type this plugin shapes (§8.8). |
| `ShutdownNotice` | Why the host is ending the SESSION (`control_plane_protocol.md` §3.3). |
| `StageInput` | What a `PlanStage` offers: the channels present in plane order, the allocation each plane is laid out in, and the one dtype (§3). |
| `StagePlan` | A stage's answer to `PlanStage`: the LARGEST output it produces (§3). |
| `StageSlot` | One slot during this stage's turn: the planes, and the header fields a stage may change. |
| `TaskHandle` | Background work the plugin runs alongside, blocking no request (§8.16). |
| `ToolContext` | What a `@tool` handler receives alongside each event: overlay access for live feedback (and the ordinary handles for end-of-gesture pushes). |
| `ViewChange` | Subscription `"view"`: where the person is looking. `open_generation` 0 is no dataset open; a new value is a new dataset. |
| `ViewResult` | The one answer to a `ViewRequest` (§8.15). `outcome` is `"APPLIED"`, `"DECLINED"` or `"REFUSED"`; `reason` names a refusal (`"NOT_ENABLED"`, `"SUPERSEDED"`, `"UNSUPPORTED"`, ...) and is `"NONE"` otherwise. A plugin reads this, never a later `ViewChanged`, to know what happened. |
| `Voxel` | Voxel(z: 'float', y: 'float', x: 'float') |
| `WidgetSize` | How large an `image` widget is drawn (§8.4): device-independent pixels, and the screen's pixel ratio. An image of `pixels` is shown one image pixel per screen pixel; any other is scaled to fit. |

## Functions and decorators

| Name | Summary |
|---|---|
| `action` | What an engaged tool can be told mid-gesture (§3.6.2); it needs a `key` or a `pane` button. |
| `appearance` | Register the handler told the host's theme and colors: once after the session starts, before any panel opens, and again whenever the person switches theme. It receives a `PluginContext` and an `Appearance`; several changes in a row may reach it as the newest alone. `ctx.appearance` holds the newest from anywhere. Usable as `@appearance` or `@appearance()`. |
| `asset` | Declare an asset the host provisions (§4): `source` is `{"kind": "manual"}` or `{"kind": "https", "url": ...}`. |
| `asset_path` | Return a verified, host-provisioned asset path. |
| `cancelled` | Whether the host has asked the request this handler serves to stop. Check it between steps; raise `Cancelled` (or return) to stop. |
| `centres` | The pixel centers an edge interval includes: `ceil(lo) ..= floor(hi)`. |
| `chunk_source` | Register the function that answers the host's wants for a CHUNKED overlay (`control_plane_protocol.md` §5.7; manifest `chunked: true`). |
| `command` | Register a command handler for a manifest-declared command id. |
| `edge_at_scale` | Convert one level-0 **edge** coordinate to a level with this scale. |
| `exporter` | Register an exporter implementation class under `exporter_id`. |
| `follow` | Register what drives a Follow the person starts from `panel_id` (§8.15): `fn(ctx, follow)`, with a `Follow`. |
| `level_scale` | The level-0 pixels per level-`level` pixel in vizi's pyramid, on an axis that is still folding. |
| `on_regions_changed` | Register `fn(ctx, change)`, called with a `RegionsChange` whenever regions are created, edited or deleted. Needs `subscriptions=["regions"]` and `data_access`. |
| `on_shape_edit_ended` | Register `fn(ctx, drag_id, outcome, detail)`, called when an edit of a region this plugin shapes ends: `outcome` is `"COMMITTED"`, `"REVERTED"` or `"CANCELLED"` (§8.8). |
| `on_shutdown` | Register the hook that runs when the host ends the session (§3.3). |
| `on_view_changed` | Register `fn(ctx, change)`, called with a `ViewChange` when the person moves `t`/`z`, changes the visible channels, selects a region, or opens or closes a dataset -- and once when the session starts. Needs `subscriptions=["view"]` and `data_access`. |
| `overlay` | Declare an overlay (§3.5). A chunked overlay served by a `@chunk_source` is declared by the decorator and needs no call here. |
| `pane` | A control-pane button (§3.6.3) for a `@tool`, an `action` or a `@command`. `icon` is relative to the directory of the script being run; `--install` copies it beside the manifest, where the host looks. |
| `panel` | Declare a panel (§3.3). `root` is a widget tree built with `.widgets` (or the same dicts written by hand). `@panel_opened` registers what runs when it opens. `view_targets` is what the panel's `moves_view` widgets may move (set-view); `follow_targets` what a Follow the person starts from it may drive (§8.15). |
| `panel_opened` | Register a handler for a manifest-declared panel's open lifecycle. |
| `plugin` | Declare the plugin's identity, which makes it a **declared** plugin. |
| `reader` | Register a reader implementation class under `reader_id`. |
| `region_shaper` | Register what computes the shape of every region of `type_name`, one of this plugin's manifest `region_types` (`control_plane_protocol.md` §8.8): `fn(ctx, edit)`, with a `ShapeEdit`. |
| `region_type` | Declare a region type this plugin shapes (§3.8) without a shaper for it -- every commit of such a region is answered `REJECTED`, so its shape cannot change. A type with a shaper is declared by `@region_shaper` and needs no call here; a call adds its `name`. |
| `report_progress` | Report progress on the request this handler is serving -- a command, a reader's open or read, an export chunk. Outside a handler it does nothing, so a helper shared with other code may call it freely. |
| `serve` | Run the plugin: bind the gRPC server at the host's endpoint, open the doorbell, and serve until the host closes the session. |
| `settings_dir` | The folder this plugin's settings persist in, created here on first use: the host names it and checks it can be made, but does not make it, so a plugin that keeps no settings leaves nothing behind. |
| `stage` | Register a processing stage class under `stage_id` (`processing_stages.md`). |
| `tool` | Register a tool implementation class under `tool_id`. |
| `trigger` | What engages a tool (§3.6.1): a `key` (`"Ctrl+J"`) or a `button` (`"right"`, `"middle"`, or `"left"` with `modifiers`). |
| `widget_geometry` | Register a handler told how large each of a panel's `image` widgets is drawn: when the panel is first shown, and whenever that changes. |
